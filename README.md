# Конструктор тестов по геометрии для oilau.kz

Веб-приложение превращает один видеоурок по геометрии (7–11 классы) в 5 тестов по 5 вопросов с точными чертежами и файлами для загрузки на платформу. Требования — в [prd.md](prd.md).

## Бесплатный прототип

Прототип опубликован как страница claude.ai: https://claude.ai/artifact/23gAw49hivCz1c611ZQ424. Там генерация идёт через аккаунт claude.ai того, кто открыл страницу, — ключ API и оплата не нужны (расходуются обычные лимиты аккаунта; при первом запуске claude.ai спросит разрешение). При первом открытии показывается готовый пример набора из 10 вопросов — он работает без обращения к Claude. Однофайловая версия собирается командой `tools/build-prototype.ps1` в `dist/prototype.html`.

## Как пользоваться

1. На claude.ai ничего настраивать не нужно. В версии на GitHub Pages нажмите **«Ключ API»** и вставьте ключ Anthropic API: он хранится только в вашем браузере и отправляется только на `api.anthropic.com`.
2. Выберите класс и язык вопросов (қазақша, русский или другой).
3. Вставьте конспект или расшифровку видео (или загрузите .txt/.md/.docx), добавьте скрины доски.
4. Нажмите **«Создать 25 вопросов»** (3–6 минут).
5. Просмотрите вопросы, исправьте помеченные «Требует проверки».
6. Скачайте Word, TXT, рисунки или всё одним архивом.

## Как устроено

| Файл | Что делает |
|---|---|
| `index.html`, `css/styles.css` | Интерфейс в стиле Apple, светлая и тёмная тема |
| `js/app.js` | Ввод урока, конвейер (разбор → 5 тестов по 2 параллельно → независимая проверка), редактирование, сохранение в localStorage |
| `js/prompts.js` | Реестр языков со словарями терминов и тексты запросов к Claude |
| `js/figure.js` | Построение чертежей из JSON: вычисляемые точки, планиметрия, координатная плоскость с графиками, стереометрия; SVG и PNG |
| `js/export.js` | TXT в формате платформы (UTF-8, CRLF, `(!)`/`(?)`), Word из OOXML, ZIP с PNG |

Claude не рисует картинку, а описывает построение (например, `{"foot": ["B","A","C"]}` — основание высоты), поэтому чертёж всегда соответствует данным задачи.

Модель по умолчанию — `claude-opus-5-5` (меняется в окне «Ключ API»). Новый язык добавляется одной записью в `LANGS` в `js/prompts.js`.
